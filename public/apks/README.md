# AppVault APK Drop Zone

Place your release Android `.apk` files here in `public/apks/`.

Examples:
- `appvault-release.apk`
- `gamevault-companion.apk`
- `vaultpad-release.apk`
- `devpulse-release.apk`
- `aerocast-release.apk`
- `zentrack-release.apk`

When building or running locally with Vite, any file placed in `public/apks/` is accessible at `/apks/filename.apk` for instant download!
